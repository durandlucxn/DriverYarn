# DriverYarn

A simple DriverYarn Framework for Predictive Analytics.

DriverYarn is aimed at developers who need a straightforward, dependable solution.

**Highlights**

- A simple DriverYarn Framework for Predictive Analytics

## Key Features

- A simple DriverYarn Framework for Predictive Analytics

## Technology Stack

- rust
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/DriverYarn.git`
2. `cd DriverYarn`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure DriverYarn, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
